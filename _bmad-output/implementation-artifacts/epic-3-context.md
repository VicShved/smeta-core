# Epic 3 Context: Справочник расценок

## Goal

Реализовать ведение глобального регионального справочника материалов и цен: импорт только из Excel (.xlsx) через маппер колонок, региональную базу 2022 и текущие цены по кварталам/ценовым зонам, а также snapshot-механизм, изолирующий уже рассчитанные версии смет от изменений справочника. Эпик создаёт источник расценок, на который опираются сопоставление извлечённых позиций (Epic 5 и Story 8.1) и детерминированный расчёт стоимости (Epic 6).

**As-built 2026-10-25:** справочник глобальный (без `company_id`), версий нет; Story 3.2 заменена Story 3.5. Поддерживаются КСР и сплит-форма ФСБЦ.

## Requirements & Constraints

- Принимается только формат `.xlsx`; прочие форматы отклоняются с понятной ошибкой.
- Перед импортом пользователь сопоставляет колонки файла (наименование, ЕИ, цена/расценка и др.) через маппер; сплит-форма распознаётся автоматически.
- Импортируются только распознанные строки; некорректные строки помещаются в `rejected` с причиной и не попадают в справочник.
- Справочник глобальный (общий для всех компаний), без `company_id`. Материал уникален по `(region_code, code)`.
- База 2022 — `material_base_price` (1:1 к материалу); текущие цены/индексы — `material_price` по `(material_id, year, quarter, zone_code)`.
- Версий/истории импортов нет: повторный импорт обновляет строки по естественному ключу.
- Позиции рассчитанных версий смет хранят snapshot расценки/ЕИ: `rate_snapshot_id`, `unit_snapshot`, `rate_amount_snapshot`.
- Импорт не изменяет активные версии смет и их итоговую стоимость; новые цены применяются только в новой версии сметы.
- Импорт и хранение — ответственность сервиса `rate-catalog`; исходники `.xlsx` — в MinIO.
- Эмбеддинги наименований (`material_embedding`, pgvector) считает фоновый воркер; они используются для сопоставления (AD-016).

## UX & Interaction Patterns

- Поток импорта (`/catalog`, роль `admin`): загрузка `.xlsx` → регион/год/квартал/зона → необязательный маппинг колонок → счётчики импорта и `rejected`.
- Просмотр справочника (`/prices`, все авторизованные): фильтры регион/год/квартал/зона, поиск по коду/наименованию, серверная пагинация; кнопка загрузки справочника ведёт на `/catalog` с текущими фильтрами.
- Пересчёт эмбеддингов — кнопка/API `POST /embeddings/jobs`, прогресс в `embedding_job`.

## Cross-Story Dependencies

- Story 3.4 расширяет 3.1 сплит-формой; Story 3.5 заменяет 3.2 региональной моделью.
- Story 3.3 задаёт контракт с Epic 6: позиции версий смет (`estimate_item`) хранят снапшоты, расчёт опирается только на них.
