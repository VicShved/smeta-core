## Intent

**Problem:** материалы были глобальными по `code`, цены 2022 хранились в каждой
квартальной строке, а ценовые зоны отсутствовали. Это не соответствует
реальной структуре данных: наименования/коды/цены 2022 грузятся в разрезе
регионов, текущие цены/коэффициенты — в разрезе кварталов и зон.

**Approach:** материал становится уникальным в пределах региона; база 2022
выносится в `material_base_price` (1:1); `material_price` хранит текущую цену,
индекс и `rate_amount` по году/кварталу/зоне. Сплит-файл при импорте обновляет
оба слоя. Зона добавляется в API, UI и период сметы.

## Boundaries & Constraints

**Always:** `.xlsx`; файл ≤ 20 МБ; лимита строк нет; невалидные строки не
прерывают импорт; регион/год/квартал/зона задаются полями формы; цена для смет
= `base_estimate_price × index_value` с fallback на текущую/старую цену;
`estimate` хранит зону периода; старый формат КСР поддерживается.

**Never:** не парсить субъект/зону/период из шапки файла; не добавлять отдельный
справочник зон (пока); не менять контракт api-gateway.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Сплит-файл | регион + год + квартал + зона | обновлены `material`, `material_base_price`, `material_price` | — |
| Повтор другого квартала | та же региональная база | новый `material_price`, база переиспользуется | — |
| Нет базы и индекса | только текущая цена | `rate_amount = current_estimate_price` | — |
| Нет источника цены | — | строка в `rejected` | HTTP 200 |
| Нет базы, есть индекс | — | строка в `rejected` `base price is not loaded` | HTTP 200 |
| Другой регион, тот же код | — | отдельный материал и эмбеддинг | — |
| Зона без периода | — | — | 422 / CHECK в БД |
| Смета без зоны | старый период | `zone_code = null`, зона выбирается при следующем сопоставлении | — |

**Acceptance Criteria:**

## Implementation Notes

- Миграция 0004 делает `TRUNCATE material CASCADE`; старые `rate_catalog_id` в
  несопоставленных сметах становятся невалидными, рассчитанные сметы сохраняют
  снапшоты.
- База 2022 обновляется из сплит-файла; при расхождении побеждает последняя
  загрузка.
- `/search` теперь обязателен `region_code`, иначе региональные дубли
  неоднозначны.
- `zone_code` — свободная строка; список существующих зон отдаёт `/zones`.
- Импорт не считает эмбеддинги: каталог коммитится, в ответе `embeddings_pending`.
- Добавлен in-process воркер rate-catalog и таблица `embedding_job`; запуск
  ручной через `POST /embeddings/jobs`, статус — `GET /embeddings/status`.
- Воркер считает батчами, обновляет `processed/total` после каждого батча,
  поддерживает `force=true` и advisory-lock от параллельных запусков.
- Импорт защищён транзакционным advisory-lock по региону/периоду/зоне; повторная
  параллельная загрузка получает `409 Conflict`.
- Таймауты импорта/матчинга подняты до 900 с (gateway/UI), nginx — 920 с.
