# Epic 8 Context: Семантическое сопоставление позиций (as-built)

<!-- As-built 2026-10-25. Эпик не входил в исходное планирование; контекст собран по build-спеке 8.1 и коду. -->

## Goal

Дать сметчику автоматическое сопоставление позиций сметы со справочником цен без ручного перебора: `rate-catalog` считает E5-эмбеддинг наименования и возвращает ближайшую по cosine цену за точный регион/год/квартал/зону, а `estimate` сохраняет расценку и confidence в позиции. LLM в сопоставлении не участвует.

## Stories

- Story 8.1: Сопоставление позиций сметы со справочником цен по эмбеддингам — done.

## Requirements & Constraints

- Период справочника (`catalog_region_code`, `catalog_year`, `catalog_quarter`, `catalog_zone`) хранится в смете; nullable для старых строк, заполняется первым успешным сопоставлением.
- Поиск идёт по наименованию через query-эмбеддинг; ближайшая цена выбирается только среди строк с ценой за точный регион/год/квартал/зону.
- Повторное сопоставление обновляет только `proposed`; `confirmed`/`corrected` не меняются и попадают в `skipped`.
- После поиска статус остаётся `proposed`; `confidence` — cosine score в `[0,1]` с 4 знаками; `needs_review` — по порогу 0.70.
- Рассчитанная или неактивная версия — `409`; чужая смета/версия — `404`; неизвестный регион — `404`; недоступная модель — `503`; недоступный справочник — `502` без частичных записей.
- Ответы в исходном порядке; ошибки — `application/problem+json`.
- `POST /search` не меняется; LLM для сопоставления не используется; чужую БД не читаем; новый сервис не вводим.

## Technical Decisions

- `rate-catalog`: `POST /v1/rate-catalog/matches`, домен `RateMatch`/`RateSearchResult`, порт `nearest_rate`, join эмбеддинга и цены периода, cosine distance, tie-break.
- `estimate`: `CatalogPeriod` в смете, порт/клиент сопоставления, endpoint `POST /v1/estimates/{id}/versions/{vid}/match-rates`, запись периода и позиции в транзакции после сетевого вызова (сессия БД закрыта).
- `api-gateway`/`ui/nginx.conf`: длинные таймауты для маршрута сопоставления.
- `ui`: форма региона/года/квартала/зоны, кнопка «Сопоставить со справочником», сохранение периода из `GET /v1/estimates/{id}`.

## UX & Interaction Patterns

- На экране сметы под итогами — форма периода и кнопка сопоставления.
- Рассчитанная версия заморожена: период и кнопка недоступны.
- После успеха показываются счётчики (`total`, `processed`, `matched`, `unmatched`, `skipped`) и таблица перезагружается с первой страницы.
- Недоступность справочника показывается текстом с кнопкой повтора; позиции и итоги остаются видимыми.
