- (direction) Источники: epics.md Story 1.3 AC, epic-1-context.md, ARCHITECTURE-SPINE AD-003, epics.md NFR-002. Режим distill: express (вход насыщенный).
- (constraint) llm.allow_cloud_fallback=false по умолчанию — блокирует облачный инференс (AD-003, NFR-002).
- (constraint) llm.redaction_mode=structure_only — во внешнюю LLM только структурно-анонимизированные фрагменты (типы полей, схема), без наименований/количеств/ЕИ.
- (constraint) Включение облачного fallback требует явного согласия и записывает аудит-событие (timestamp, инициатор, причина, объём структурных блоков).
- (constraint) Все события attempt/fallback/denied/allowed сохраняются в журнале аудита.
- (capability) CAP-1: блокировка облачного инференса по умолчанию (deny + событие denied).
- (capability) CAP-2: структурная редукция при fallback (structure_only → только схемы/типы, без значений).
- (capability) CAP-3: аудит всех LLM-событий (attempt/fallback/denied/allowed с timestamp, инициатор, причина, объём).
- (capability) CAP-4: явное согласие для включения fallback (включение фиксируется в аудите).
- (direction) Why: владелец данных требует гарантии, что данные смет не утекают во внешнюю LLM без явного согласия — конфиденциальность сметных данных (mandate + pain).
- (decision) Non-goal: реализация самого облачного провайдера LLM — только политика/интерфейс, не интеграция с внешним API.
- (decision) Non-goal: UI для управления политикой fallback.
- (decision) Non-goal: отдельная БД для аудита — MVP использует журнал (файловый/логгер).
- (direction) Success signal: при дефолтной конфигурации облачный запрос блокируется с событием denied в аудите; при structure_only наружу уходят только схемы без значений.
- (assumption) Предположено, что llm-gateway — единственный компонент, реализующий политику fallback (AD-003 binds llm-gateway, pdf-extract, mapping-service; но реализация политики — в llm-gateway).
- (assumption) Предположено, что облачный провайдер будет подключён позже; в этом спеке только интерфейс/политика.
- (question) Какой конкретный backend для журнала аудита в MVP — файл (JSONL) или логгер? Уточнить при implement.
- (question) Как передаётся явное согласие на включение fallback — env-флаг, API-эндпоинт, или оба? Уточнить при implement.

- (event) Self-validate Pass 2 (Preservation): OK — все AC Story 1.3 (deny+denied, structure_only без значений, explicit consent+audit, все 4 события) + AD-003 + NFR-002 вошли в kernel. Wrapper-only: нет.
